2. Physics core (uq_core.ballistics)

  • State: (x, y, vx, vy). With k = ½ρS:
    • a = −g·ŷ − (k·C_d/m)·|v|·v + (k·C_l/m)·|v|·v⊥
    • Mass enters through the drag/lift-to-mass ratio, so heavier means less affected by drag.
  • Solver: explicit Euler with step dt. It stops when y < 0 and interpolates linearly to get the exact impact point.
  • Vectorised over samples: one numpy loop advances N trajectories at once, so 10k Monte Carlo runs take well under a second.
  • Inputs: v₀, θ, C_d, C_l, m, plus optional wind speed and air density ρ.
  • Quantities of interest (QoI): range, maximum height, and optionally time of flight and impact speed.

3. Features (one tab per lesson)

  1. Deterministic simulator
    • Sliders for each parameter and a live trajectory.
    • Overlay of the drag-free parabola (the exact solution) for comparison.
    • A dt slider that shows Euler's error and convergence: a first lesson on numerical (non-parametric) uncertainty.
  2. Uncertainty propagation (Monte Carlo)
    • Each parameter can switch between "fixed" and "uncertain" with a chosen distribution (normal, uniform, lognormal or truncated) and its mean and std.dev.
    • Views: spaghetti plot of trajectories, histogram and density plot of each QoI, mean/std/quantiles, P(|range − target| > tol), and a convergence plot of the estimate's confidence interval against N.

  3. Design of experiments
    • Methods: random, Latin hypercube (LHS), Sobol/Halton, and full factorial.

    • Models: polynomial regression, Gaussian process (kriging) and random forest, optionally a small neural network (MLP).
    • Views: train/test parity plot, Q² and RMSE, learning curve against training-set size, 2D response surface (contour) with the training points, and a 1D slice showing the GP's confidence band.
  5. Sensitivity analysis
    • Methods: one-at-a-time tornado plot, Morris screening, and Sobol indices (first-order and total) with bootstrap confidence intervals.

"""Ballistic model: point mass with drag, lift and horizontal wind.

State (x, y, vx, vy). With k = 0.5 * rho * S and relative velocity u = v - w
(w = horizontal wind, positive = tailwind):

    a = -g * y_hat - (k * Cd / m) * |u| * u + (k * Cl / m) * |u| * perp(u)

where perp(u) = (-u_y, u_x) is u rotated by +90 deg, so a positive Cl
(backspin) lifts the projectile while it travels forward.

All functions are vectorised: every input may be a scalar or an array of
shape (N,), and N trajectories are advanced together in one numpy loop.
"""
from __future__ import annotations

from dataclasses import dataclass

import numpy as np

G = 9.81  # gravity [m/s^2]
RHO = 1.225  # air density [kg/m^3]
DIAMETER = 0.22  # ball diameter [m] (football-sized)
AREA = np.pi * DIAMETER**2 / 4  # reference area [m^2]
K_AERO = 0.5 * RHO * AREA

T_MAX = 60.0  # safety cap on flight time [s]


@dataclass
class SimResult:
    range: np.ndarray  # horizontal distance at impact [m]
    max_height: np.ndarray  # apex height [m]
    flight_time: np.ndarray  # time of flight [s]
    impact_speed: np.ndarray  # ground speed at impact [m/s]
    landed: np.ndarray  # False if the projectile did not land before T_MAX
    trajectories: list[np.ndarray] | None = None  # list of (n_pts, 2) arrays

    def qoi(self, name: str) -> np.ndarray:
        return {
            "range": self.range,
            "max_height": self.max_height,
            "flight_time": self.flight_time,
            "impact_speed": self.impact_speed,
        }[name]


def _acceleration(vx, vy, cd, cl, mass, wind):
    ux = vx - wind
    uy = vy
    speed = np.sqrt(ux * ux + uy * uy)
    kd = K_AERO * cd / mass * speed
    kl = K_AERO * cl / mass * speed
    ax = -kd * ux - kl * uy
    ay = -G - kd * uy + kl * ux
    return ax, ay


def simulate(
    v0,
    theta_deg,
    cd=0.0,
    cl=0.0,
    mass=1.0,
    wind=0.0,
    dt=0.01,
    scheme: str = "euler",
    record: int = 0,
    max_points: int = 200,
) -> SimResult:
    """Integrate N trajectories until each one hits the ground (y = 0).

    `dt` may itself be an array (one step size per trajectory), which is how
    the dt-convergence study is vectorised. `record` is the number of
    trajectories (the first ones) whose path is stored, downsampled to at
    most `max_points` points.
    """
    v0, theta, cd, cl, mass, wind, dt = np.broadcast_arrays(
        *(np.atleast_1d(np.asarray(a, dtype=float)) for a in (v0, theta_deg, cd, cl, mass, wind, dt))
    )
    n = v0.shape[0]
    th = np.radians(theta)
    x = np.zeros(n)
    y = np.zeros(n)
    vx = v0 * np.cos(th)
    vy = v0 * np.sin(th)
    t = np.zeros(n)

    active = np.ones(n, dtype=bool)
    rng_out = np.full(n, np.nan)
    tof = np.full(n, np.nan)
    v_imp = np.full(n, np.nan)
    ymax = np.zeros(n)

    record = min(record, n)
    paths: list[list[tuple[float, float]]] = [[(0.0, 0.0)] for _ in range(record)]

    max_steps = int(np.ceil(T_MAX / dt.min()))
    for _ in range(max_steps):
        if scheme == "rk4":
            def f(s):
                ax_, ay_ = _acceleration(s[2], s[3], cd, cl, mass, wind)
                return np.array([s[2], s[3], ax_, ay_])
            s = np.array([x, y, vx, vy])
            k1 = f(s)
            k2 = f(s + 0.5 * dt * k1)
            k3 = f(s + 0.5 * dt * k2)
            k4 = f(s + dt * k3)
            xn, yn, vxn, vyn = s + dt / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
        else:  # explicit Euler
            ax, ay = _acceleration(vx, vy, cd, cl, mass, wind)
            xn = x + dt * vx
            yn = y + dt * vy
            vxn = vx + dt * ax
            vyn = vy + dt * ay

        # Trajectories crossing the ground during this step: interpolate linearly.
        hit = active & (yn < 0.0) & (t > 0.0 + 0.5 * dt)
        if hit.any():
            frac = y[hit] / (y[hit] - yn[hit])
            rng_out[hit] = x[hit] + frac * (xn[hit] - x[hit])
            tof[hit] = t[hit] + frac * dt[hit]
            vxi = vx[hit] + frac * (vxn[hit] - vx[hit])
            vyi = vy[hit] + frac * (vyn[hit] - vy[hit])
            v_imp[hit] = np.hypot(vxi, vyi)
            for i in np.flatnonzero(hit[:record]):
                paths[i].append((float(rng_out[i]), 0.0))
            active &= ~hit

        x = np.where(active, xn, x)
        y = np.where(active, yn, y)
        vx = np.where(active, vxn, vx)
        vy = np.where(active, vyn, vy)
        t = np.where(active, t + dt, t)
        ymax = np.maximum(ymax, np.where(active, y, 0.0))
        for i in np.flatnonzero(active[:record]):
            paths[i].append((float(x[i]), float(y[i])))
        if not active.any():
            break

    landed = ~active
    # Projectiles still flying at T_MAX: report their current position.
    rng_out = np.where(landed, rng_out, x)
    tof = np.where(landed, tof, t)
    v_imp = np.where(landed, v_imp, np.hypot(vx, vy))

    trajectories = None
    if record:
        trajectories = []
        for p in paths:
            arr = np.asarray(p)
            if len(arr) > max_points:
                idx = np.unique(np.r_[np.linspace(0, len(arr) - 1, max_points).astype(int), len(arr) - 1])
                arr = arr[idx]
            trajectories.append(arr)

    return SimResult(rng_out, ymax, tof, v_imp, landed, trajectories)


def vacuum_trajectory(v0: float, theta_deg: float, n_points: int = 100) -> dict:
    """Closed-form drag-free parabola (the reference solution)."""
    th = np.radians(theta_deg)
    vx, vy = v0 * np.cos(th), v0 * np.sin(th)
    tof = 2 * vy / G
    t = np.linspace(0, tof, n_points)
    return {
        "x": (vx * t).tolist(),
        "y": (vy * t - 0.5 * G * t**2).tolist(),
        "range": float(v0**2 * np.sin(2 * th) / G),
        "max_height": float(vy**2 / (2 * G)),
        "flight_time": float(tof),
    }

"""Input parameters, their probability distributions, and model evaluation.

A *spec* is a dict  name -> {"value", "std", "dist", "uncertain"}  where
`value` is the nominal value (= the mean when the parameter is uncertain).
Sampling always goes through the unit hypercube: a design U in [0, 1]^d
(random, LHS, Sobol...) is mapped to physical values by the inverse CDF of
each marginal. This makes Monte Carlo, DoE and Sobol share the same code.
"""
from __future__ import annotations

from dataclasses import dataclass

from scipy import stats

@dataclass(frozen=True)
class ParamInfo:
    name: str
    label: str
    unit: str
    lo: float  # physical bounds (samples are clipped to them)
    hi: float
    value: float  # default nominal value
    std: float  # default standard deviation
    uncertain: bool  # uncertain by default?
    step: float

        ParamInfo("v0", "Initial speed", "m/s", 1.0, 80.0, 30.0, 1.0, True, 0.5),
        ParamInfo("theta", "Launch angle", "deg", 1.0, 89.0, 40.0, 1.5, True, 0.5),

        ParamInfo("mass", "Mass", "kg", 0.05, 5.0, 0.43, 0.01, False, 0.01),
        ParamInfo("wind", "Wind speed (tail +)", "m/s", -25.0, 25.0, 0.0, 2.0, True, 0.5),

}

_EPS = 1e-9


def default_spec() -> dict:
    return {
        n: {"value": p.value, "std": p.std, "dist": "normal", "uncertain": p.uncertain}
        for n, p in PARAMS.items()
    }


def normalize_spec(spec: dict | None) -> dict:
    """Fill missing entries with defaults and validate values."""
    full = default_spec()
    for name, entry in (spec or {}).items():
        if name not in full:
            raise ValueError(f"unknown parameter {name!r}")
        full[name].update({k: v for k, v in entry.items() if v is not None})
        e = full[name]
        if e["dist"] not in DISTS:
            raise ValueError(f"unknown distribution {e['dist']!r}")
        if e["std"] < 0:
            raise ValueError(f"negative std for {name}")
        if e["dist"] == "lognormal" and e["uncertain"] and e["value"] <= 0:
            raise ValueError(f"lognormal needs a positive mean ({name})")
    return full


def nominal(spec: dict) -> dict[str, float]:
    return {n: float(spec[n]["value"]) for n in NAMES}


def uncertain_names(spec: dict) -> list[str]:
    return [n for n in NAMES if spec[n]["uncertain"] and spec[n]["std"] > 0]


def marginal(entry: dict):
    """Frozen scipy distribution for one parameter."""
    m, s = float(entry["value"]), float(entry["std"])
    if entry["dist"] == "uniform":
        half = np.sqrt(3.0) * s  # uniform on [m - h, m + h] has std h / sqrt(3)
        return stats.uniform(loc=m - half, scale=2 * half)
    if entry["dist"] == "lognormal":
        sig2 = np.log1p((s / m) ** 2)
        return stats.lognorm(s=np.sqrt(sig2), scale=m * np.exp(-sig2 / 2))
    return stats.norm(loc=m, scale=s)


def from_unit(spec: dict, names: list[str], U: np.ndarray) -> np.ndarray:
    """Map U in (0,1)^d to physical values through the inverse CDFs."""
    U = np.clip(np.atleast_2d(U), _EPS, 1 - _EPS)
    X = np.empty_like(U, dtype=float)
    for j, n in enumerate(names):
        X[:, j] = np.clip(marginal(spec[n]).ppf(U[:, j]), PARAMS[n].lo, PARAMS[n].hi)
    return X


def box_from_spec(spec: dict, names: list[str], k: float = 3.0) -> list[tuple[float, float]]:
    """Default training box: mean +/- k std, clipped to physical bounds."""
    box = []
    for n in names:
        d = marginal(spec[n])
        q = stats.norm.cdf([-k, k])
        lo, hi = d.ppf(q) if spec[n]["std"] > 0 else (spec[n]["value"],) * 2
        lo, hi = max(lo, PARAMS[n].lo), min(hi, PARAMS[n].hi)
        if hi - lo < 1e-9:
            w = max(PARAMS[n].step, 1e-3)
            lo, hi = max(lo - w, PARAMS[n].lo), min(hi + w, PARAMS[n].hi)
        box.append((float(lo), float(hi)))
    return box

    """Columns of X for `names`, nominal values for every other parameter."""
    X = np.atleast_2d(X)

    out = {n: np.full(X.shape[0], base[n]) for n in NAMES}
    for j, n in enumerate(names):

    return out

from __future__ import annotations

import numpy as np
from scipy.spatial.distance import pdist
from scipy.stats import qmc

METHODS = ["random", "lhs", "lhs_opt", "sobol", "halton", "factorial"]


def unit_design(method: str, n: int, d: int, seed: int | None = 0) -> np.ndarray:
    rng = np.random.default_rng(seed)
    if method == "random":
        return rng.random((n, d))
    if method == "lhs":
        return qmc.LatinHypercube(d, rng=rng).random(n)
    if method == "lhs_opt":  # LHS improved for centred discrepancy
        return qmc.LatinHypercube(d, optimization="random-cd", rng=rng).random(n)
    if method == "sobol":
        return qmc.Sobol(d, scramble=True, rng=rng).random(n)
    if method == "halton":
        return qmc.Halton(d, scramble=True, rng=rng).random(n)
    if method == "factorial":
        levels = max(2, int(round(n ** (1.0 / d))))
        axes = [np.linspace(0, 1, levels)] * d
        return np.stack(np.meshgrid(*axes, indexing="ij"), -1).reshape(-1, d)
    raise ValueError(f"unknown DoE method {method!r}")


def scale(U: np.ndarray, box) -> np.ndarray:
    lo = np.array([b[0] for b in box])
    hi = np.array([b[1] for b in box])
    return lo + U * (hi - lo)


def to_unit(X: np.ndarray, box) -> np.ndarray:
    lo = np.array([b[0] for b in box])
    hi = np.array([b[1] for b in box])
    return (X - lo) / (hi - lo)


def metrics(U: np.ndarray) -> dict:
    """Space-filling quality: larger min-distance and smaller discrepancy are better."""
    U = np.clip(U, 0, 1)
    md = float(pdist(U).min()) if len(U) > 1 else float("nan")
    return {
        "min_distance": md,
        "discrepancy": float(qmc.discrepancy(U, method="CD")),
        "n": int(len(U)),
    }

from __future__ import annotations

def summarize(y: np.ndarray) -> dict:
    y = np.asarray(y, dtype=float)
    q = np.percentile(y, [5, 25, 50, 75, 95])
    return {
        "mean": float(y.mean()),
        "std": float(y.std(ddof=1)) if len(y) > 1 else 0.0,
        "min": float(y.min()),
        "max": float(y.max()),
        "p05": float(q[0]), "p25": float(q[1]), "p50": float(q[2]), "p75": float(q[3]), "p95": float(q[4]),
    }


def kde(y: np.ndarray, n_points: int = 200) -> dict:
    y = np.asarray(y, dtype=float)
    lo, hi = y.min(), y.max()
    pad = 0.1 * (hi - lo) if hi > lo else 1.0
    xs = np.linspace(lo - pad, hi + pad, n_points)
    if y.std() < 1e-12:
        return {"x": xs.tolist(), "y": np.zeros_like(xs).tolist()}
    return {"x": xs.tolist(), "y": stats.gaussian_kde(y)(xs).tolist()}


def convergence(y: np.ndarray, n_points: int = 30) -> dict:
    """Running mean with its 95% confidence interval: the MC error shrinks as 1/sqrt(n)."""
    n = len(y)
    ns = np.unique(np.logspace(1, np.log10(n), n_points).astype(int))
    ns = ns[ns <= n]
    csum = np.cumsum(y)
    csum2 = np.cumsum(y**2)
    mean = csum[ns - 1] / ns
    var = np.maximum(csum2[ns - 1] / ns - mean**2, 0) * ns / np.maximum(ns - 1, 1)
    half = 1.96 * np.sqrt(var / ns)
    return {"n": ns.tolist(), "mean": mean.tolist(), "lo": (mean - half).tolist(),
            "hi": (mean + half).tolist(), "std": np.sqrt(var).tolist()}


def fosm(spec: dict, qoi: str, dt: float) -> dict:
    """First-order second-moment: Var[f] ~ sum_i (df/dx_i)^2 sigma_i^2 around the mean."""
    names = uncertain_names(spec)
    base = nominal(spec)
    if not names:
        y0 = float(run_model(full_inputs(spec, [], np.zeros((1, 0))), dt).qoi(qoi)[0])
        return {"mean": y0, "std": 0.0, "gradient": {}, "contrib": {}}
    d = len(names)
    x0 = np.array([base[n] for n in names])
    h = np.array([max(0.05 * spec[n]["std"], 1e-6) for n in names])
    X = np.repeat(x0[None, :], 2 * d + 1, axis=0)
    for j in range(d):
        X[1 + 2 * j, j] += h[j]
        X[2 + 2 * j, j] -= h[j]
    # Use a fine step so that the Euler discretisation does not pollute the gradient.
    y = run_model(full_inputs(spec, names, X), min(dt, 0.002)).qoi(qoi)
    grad = np.array([(y[1 + 2 * j] - y[2 + 2 * j]) / (2 * h[j]) for j in range(d)])
    sig = np.array([marginal(spec[n]).std() for n in names])
    terms = (grad * sig) ** 2
    var = terms.sum()
    return {
        "mean": float(y[0]),
        "std": float(np.sqrt(var)),
        "gradient": {n: float(g) for n, g in zip(names, grad)},
        "contrib": {n: float(t / var) if var > 0 else 0.0 for n, t in zip(names, terms)},
    }

    "poly2": "Quadratic polynomial",
    "poly3": "Cubic polynomial",

    "rf": "Random forest",
    "mlp": "Neural network (MLP)",
}

def make_estimator(kind: str, d: int, seed: int = 0):
    if kind.startswith("poly"):
        deg = int(kind[4:])
        return make_pipeline(PolynomialFeatures(deg), Ridge(alpha=1e-8))
    if kind == "gp":
        kernel = ConstantKernel(1.0, (1e-3, 1e3)) * RBF(np.full(d, 0.5), (1e-2, 1e2)) + WhiteKernel(1e-6, (1e-10, 1e-1))
        return GaussianProcessRegressor(kernel, normalize_y=True, n_restarts_optimizer=2, random_state=seed)
    if kind == "rf":
        return RandomForestRegressor(n_estimators=200, random_state=seed)
    if kind == "mlp":
        mlp = MLPRegressor((64, 64), activation="tanh", max_iter=4000, learning_rate_init=3e-3, random_state=seed)
        return TransformedTargetRegressor(regressor=mlp, transformer=StandardScaler())
    raise ValueError(f"unknown surrogate kind {kind!r}")


@dataclass
class Surrogate:
    kind: str
    names: list[str]
    box: list[tuple[float, float]]
    qoi: str
    dt: float
    spec: dict
    X: np.ndarray
    y: np.ndarray
    estimator: object = None
    id: str = field(default_factory=lambda: uuid.uuid4().hex[:12])
    train_time: float = 0.0

    def fit(self, seed: int = 0):
        t = time.perf_counter()
        with warnings.catch_warnings():
            warnings.simplefilter("ignore", ConvergenceWarning)
            self.estimator = make_estimator(self.kind, len(self.names), seed)
            self.estimator.fit(doe.to_unit(self.X, self.box), self.y)
        self.train_time = time.perf_counter() - t
        return self

    def predict(self, X: np.ndarray, return_std: bool = False, batch: int = 20000):
        U = doe.to_unit(np.atleast_2d(X), self.box)
        means, stds = [], []
        for i in range(0, len(U), batch):
            u = U[i:i + batch]
            if self.kind == "gp" and return_std:
                m, s = self.estimator.predict(u, return_std=True)
            elif self.kind == "rf" and return_std:
                per_tree = np.stack([t.predict(u) for t in self.estimator.estimators_])
                m, s = per_tree.mean(0), per_tree.std(0)
            else:
                m, s = self.estimator.predict(u), None
            means.append(m)
            stds.append(s)
        mean = np.concatenate(means) if means else np.zeros(0)
        if not return_std:
            return mean
        std = None if stds[0] is None else np.concatenate(stds)
        return mean, std

    def has_std(self) -> bool:
        return self.kind in ("gp", "rf")

    def anchor(self) -> np.ndarray:
        """Point where slices are taken: nominal values clipped into the box."""
        base = nominal(self.spec)
        return np.array([np.clip(base[n], lo, hi) for n, (lo, hi) in zip(self.names, self.box)])

        info = {"id": self.id, "kind": self.kind, "label": KINDS[self.kind], "names": self.names,

                "train_time": self.train_time}
        if self.kind == "gp":

        return info

"""Sensitivity analysis: one-at-a-time (tornado), Morris screening, Sobol indices.

Every method takes a model function  fn(X) -> y  where the columns of X are
the uncertain parameters `names` in physical units. That function is either
the true simulator or a trained surrogate, which is the whole point: Sobol
indices need N (d + 2) runs, cheap on a surrogate.
"""
from __future__ import annotations

import time
import warnings
from typing import Callable

import numpy as np
from scipy.stats import qmc

from .params import from_unit, marginal, nominal

ModelFn = Callable[[np.ndarray], np.ndarray]


class CountingModel:
    """Wraps a model function to count evaluations and time them."""

    def __init__(self, fn: ModelFn):
        self.fn, self.calls, self.seconds = fn, 0, 0.0

    def __call__(self, X):
        t = time.perf_counter()
        y = self.fn(X)
        self.seconds += time.perf_counter() - t
        self.calls += len(X)
        return y

    def cost(self) -> dict:
        return {"evaluations": self.calls, "seconds": self.seconds}


def oat(fn: ModelFn, spec: dict, names: list[str], q_lo: float = 0.05, q_hi: float = 0.95) -> dict:
    """Tornado: move one input from its q_lo to its q_hi quantile, others at nominal."""
    model = CountingModel(fn)
    base = nominal(spec)
    x0 = np.array([base[n] for n in names])
    X = [x0]
    lows, highs = [], []
    for j, n in enumerate(names):
        d = marginal(spec[n])
        lo, hi = x0.copy(), x0.copy()
        lo[j], hi[j] = d.ppf(q_lo), d.ppf(q_hi)
        lows.append(float(lo[j]))
        highs.append(float(hi[j]))
        X += [lo, hi]
    y = model(np.array(X))
    rows = [{"name": n, "x_lo": lows[j], "x_hi": highs[j], "y_lo": float(y[1 + 2 * j]),
             "y_hi": float(y[2 + 2 * j]), "swing": float(abs(y[2 + 2 * j] - y[1 + 2 * j]))}
            for j, n in enumerate(names)]
    rows.sort(key=lambda r: -r["swing"])
    return {"base": float(y[0]), "rows": rows, "quantiles": [q_lo, q_hi], "cost": model.cost()}


def morris(fn: ModelFn, spec: dict, names: list[str], r: int = 20, levels: int = 4, seed: int = 0) -> dict:
    """Morris elementary effects on r random one-at-a-time trajectories (r (d+1) runs).

    The grid lives in probability space (quantiles 1%..99%), so each input is
    explored according to its distribution. mu* ranks importance; a large
    sigma signals non-linearity or interactions.
    """
    model = CountingModel(fn)
    rng = np.random.default_rng(seed)
    d = len(names)
    delta = levels / (2 * (levels - 1))
    grid = np.arange(levels) / (levels - 1)
    starts = grid[grid <= 1 - delta + 1e-12]
    ee = np.zeros((r, d))
    for t in range(r):
        u = rng.choice(starts, d)
        order = rng.permutation(d)
        pts = [u.copy()]
        for j in order:
            u = u.copy()
            u[j] += delta
            pts.append(u)
        P = 0.01 + 0.98 * np.array(pts)  # avoid the infinite tails of the ppf
        y = model(from_unit(spec, names, P))
        for k, j in enumerate(order):
            ee[t, j] = (y[k + 1] - y[k]) / delta
    rows = [{"name": n, "mu": float(ee[:, j].mean()), "mu_star": float(np.abs(ee[:, j]).mean()),
             "sigma": float(ee[:, j].std(ddof=1))} for j, n in enumerate(names)]
    return {"rows": rows, "r": r, "levels": levels, "cost": model.cost(),
            "effects": {n: ee[:, j].tolist() for j, n in enumerate(names)}}


def sobol(fn: ModelFn, spec: dict, names: list[str], n_base: int = 1024, seed: int = 0,
          n_boot: int = 200) -> dict:
    """First-order (Saltelli 2010) and total (Jansen) Sobol indices, N (d + 2) runs."""
    model = CountingModel(fn)
    d = len(names)
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        U = qmc.Sobol(2 * d, scramble=True, rng=np.random.default_rng(seed)).random(n_base)
    A, B = U[:, :d], U[:, d:]
    blocks = [A, B]
    for j in range(d):
        AB = A.copy()
        AB[:, j] = B[:, j]
        blocks.append(AB)
    y = model(from_unit(spec, names, np.vstack(blocks))).reshape(d + 2, n_base)
    fA, fB, fAB = y[0], y[1], y[2:]

    def indices(idx):
        a, b, ab = fA[idx], fB[idx], fAB[:, idx]
        var = np.var(np.r_[a, b])
        if var < 1e-15:
            return np.zeros(d), np.zeros(d), var
        s1 = np.mean(b * (ab - a), axis=1) / var
        st = 0.5 * np.mean((a - ab) ** 2, axis=1) / var
        return s1, st, var

    s1, st, var = indices(np.arange(n_base))
    rng = np.random.default_rng(seed + 1)
    boot = [indices(rng.integers(0, n_base, n_base)) for _ in range(n_boot)]
    b1 = np.array([b[0] for b in boot])
    bt = np.array([b[1] for b in boot])
    rows = [{"name": n, "S1": float(s1[j]), "ST": float(st[j]),
             "S1_ci": np.percentile(b1[:, j], [2.5, 97.5]).tolist(),
             "ST_ci": np.percentile(bt[:, j], [2.5, 97.5]).tolist()} for j, n in enumerate(names)]
    return {"rows": rows, "variance": float(var), "sum_S1": float(s1.sum()), "n_base": n_base,
            "cost": model.cost()}

"""Robust design: choose the means of 1-2 controllable inputs so that the QoI
hits a target despite uncertainty (input tolerances + nuisance parameters
such as the wind).

Every uncertain parameter contributes a random deviation e_j drawn from its
marginal (centred on its mean). For a candidate design mu, the samples are
x_j = mu_j + e_j for design variables and x_j = value_j + e_j otherwise.
The same deviations are reused for every design (common random numbers), so
the objective landscape is smooth and comparisons between designs are fair.

Three objectives are compared:
  deterministic : (f(mu, nominal noise) - T)^2         -- ignores uncertainty
  mean_var      : (E[f] - T)^2 + lambda * Var[f]        -- trade bias vs spread
  chance        : 1 - P(|f - T| <= tol)                  -- maximise hit probability
"""
from __future__ import annotations

import time
import warnings

import numpy as np
from scipy.optimize import minimize
from scipy.special import expit
from scipy.stats import norm, qmc

from . import doe
from .params import NAMES, PARAMS, box_from_spec, evaluate, from_unit, marginal, nominal, uncertain_names
from .propagation import kde, summarize
from .surrogate import Surrogate, scores, store, test_set

OBJECTIVES = {"deterministic": "Deterministic (nominal hit)", "mean_var": "Mean-variance",
              "chance": "Max hit probability"}


def _deviations(spec, names, n, seed):
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        U = qmc.Sobol(max(len(names), 1), scramble=True, rng=np.random.default_rng(seed)).random(n)
    U = np.clip(U[:, :len(names)], 1e-9, 1 - 1e-9)
    E = np.empty((n, len(names)))
    for j, nm in enumerate(names):
        E[:, j] = marginal(spec[nm]).ppf(U[:, j]) - spec[nm]["value"]
    return E


class Problem:
    def __init__(self, spec, design, qoi, target, tol, lam, n_mc, dt, seed, fn, inputs):
        self.spec, self.design, self.qoi = spec, design, qoi
        self.target, self.tol, self.lam = target, tol, lam
        self.noise = uncertain_names(spec)
        self.E = _deviations(spec, self.noise, n_mc, seed)
        self.fn, self.inputs = fn, inputs  # fn takes X with columns = inputs
        self.base = nominal(spec)
        self.calls = 0

    def _points(self, M: np.ndarray, E: np.ndarray) -> np.ndarray:
        """All (design, sample) combinations -> rows of X (columns = self.inputs)."""
        g, n = len(M), len(E)
        X = np.empty((g, n, len(self.inputs)))
        for c, nm in enumerate(self.inputs):
            centre = M[:, self.design.index(nm)][:, None] if nm in self.design else np.full((g, 1), self.base[nm])
            dev = E[None, :, self.noise.index(nm)] if nm in self.noise else 0.0
            X[:, :, c] = np.clip(centre + dev, PARAMS[nm].lo, PARAMS[nm].hi)
        return X.reshape(g * n, -1)

    def stats(self, M: np.ndarray) -> dict:
        M = np.atleast_2d(M)
        n = len(self.E)
        y = self.fn(self._points(M, self.E)).reshape(len(M), n)
        y_nom = self.fn(self._points(M, np.zeros((1, len(self.noise))))).ravel()
        self.calls += y.size + y_nom.size
        dev = np.abs(y - self.target)
        return {"mean": y.mean(1), "std": y.std(1), "nominal": y_nom,
                "p_hit": (dev <= self.tol).mean(1),
                # smooth version of the indicator, used by the optimiser
                "p_smooth": expit((self.tol - dev) / (0.05 * self.tol + 1e-9)).mean(1)}

    def objective(self, kind: str, st: dict) -> np.ndarray:
        if kind == "deterministic":
            return (st["nominal"] - self.target) ** 2
        if kind == "mean_var":
            return (st["mean"] - self.target) ** 2 + self.lam * st["std"] ** 2
        return 1.0 - st["p_smooth"]


def _surrogate_fn(spec, design, bounds, qoi, dt, n_train, kind, seed):
    """Train a surrogate covering the design box widened by the input spread."""
    inputs = [n for n in NAMES if n in design or n in uncertain_names(spec)]
    box = []
    for nm in inputs:
        lo, hi = box_from_spec(spec, [nm], k=4.0)[0]
        if nm in design:
            spread = 4.0 * spec[nm]["std"] if spec[nm]["uncertain"] else 0.0
            b = bounds[design.index(nm)]
            lo, hi = max(b[0] - spread, PARAMS[nm].lo), min(b[1] + spread, PARAMS[nm].hi)
        box.append((float(lo), float(hi)))
    X = doe.scale(doe.unit_design("lhs_opt", n_train, len(inputs), seed), box)
    s = Surrogate(kind, inputs, box, qoi, dt, spec, X, evaluate(spec, inputs, X, qoi, dt)).fit(seed)
    store(s)
    Xt, yt = test_set(spec, inputs, box, qoi, dt, 400, seed)
    return s, inputs, scores(yt, s.predict(Xt))

             grid: int = 31, use_surrogate: bool = True, surrogate_kind: str = "gp",
             n_train: int = 200, dt: float = 0.01, seed: int = 0, n_validate: int = 4000) -> dict:

        raise ValueError("choose one or two design variables")
    t0 = time.perf_counter()
    out: dict = {"design": design, "bounds": bounds, "noise": uncertain_names(spec)}
    if use_surrogate:
        s, inputs, sc = _surrogate_fn(spec, design, bounds, qoi, dt, n_train, surrogate_kind, seed)
        fn = s.predict
        out["surrogate"] = {**s.describe(), "test": sc}
    else:

        fn = lambda X: evaluate(spec, inputs, X, qoi, dt)  # noqa: E731

    axes = [np.linspace(lo, hi, grid if len(design) == 2 else 4 * grid) for lo, hi in bounds]
    mesh = np.meshgrid(*axes, indexing="xy")
    M = np.column_stack([m.ravel() for m in mesh])
    st = pb.stats(M)
    shape = mesh[0].shape
    out["grid"] = {"axes": [a.tolist() for a in axes],

    out["grid"]["objective"] = {k: pb.objective(k, st).reshape(shape).tolist() for k in OBJECTIVES}

    # 2) Optimum of each objective: best grid point, then Nelder-Mead refinement.
    lo = np.array([b[0] for b in bounds])
    hi = np.array([b[1] for b in bounds])
    start_nom = np.clip([nominal(spec)[d] for d in design], lo, hi)

        # The deterministic optimum is a whole curve of designs; start from the
        # current nominal design, as a naive engineer would.
        x_start = start_nom if kind == "deterministic" else M[np.argmin(J)]

        def f(x, kind=kind):
            x = np.clip(x, lo, hi)
            return float(pb.objective(kind, pb.stats(x[None, :]))[0])

        res = minimize(f, x_start, method="Nelder-Mead",
                       options={"xatol": 1e-3 * float(np.max(hi - lo)), "fatol": 1e-10, "maxiter": 300})

        s_opt = pb.stats(x[None, :])
        optima[kind] = {"x": dict(zip(design, x.tolist())), "objective": float(pb.objective(kind, s_opt)[0]),

                        "nominal": float(s_opt["nominal"][0]), "p_hit": float(s_opt["p_hit"][0])}
    out["optima"] = optima
    out["model_calls"] = pb.calls
    out["seconds_optim"] = time.perf_counter() - t0

    # 3) Check each optimum on the true model with fresh samples.
    names = uncertain_names(spec)
    rng = np.random.default_rng(seed + 99)
    for kind, opt in optima.items():
        sp = {k: dict(v) for k, v in spec.items()}

        else:
            y = evaluate(sp, [], np.zeros((1, 0)), qoi, dt)
        opt["validation"] = {**summarize(y), "p_hit": float((np.abs(y - target) <= tol).mean()),
                             "kde": kde(y), "values": np.round(y[:2000], 3).tolist()}
    return out

def _clean(obj: Any) -> Any:
    """numpy -> python, NaN/inf -> None, so the payload is valid JSON."""
    if isinstance(obj, dict):
        return {str(k): _clean(v) for k, v in obj.items()}
    if isinstance(obj, (list, tuple)):
        return [_clean(v) for v in obj]
    if isinstance(obj, np.ndarray):
        return _clean(obj.tolist())
    if isinstance(obj, (np.floating, float)):
        f = float(obj)
        return f if math.isfinite(f) else None
    if isinstance(obj, np.integer):
        return int(obj)
    if isinstance(obj, np.bool_):
        return bool(obj)
    return obj

        cols = [names.index(n) if n in names else None for n in s.names]

            Z = np.empty((len(X), len(s.names)))
            for c, j in enumerate(cols):
                Z[:, c] = X[:, j] if j is not None else base[s.names[c]]
            return s.predict(Z)
    else:
        def fn(X):
            return params.evaluate(spec, names, X, req.qoi, req.dt)

        out = sensitivity.oat(fn, spec, names)
    elif req.method == "morris":
        out = sensitivity.morris(fn, spec, names, req.r, req.levels, req.seed)

export async function post<T = any>(path: string, body: unknown, signal?: AbortSignal): Promise<T> {
  const res = await fetch(`/api/${path}`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
    signal,
  });
  const data = await res.json().catch(() => ({}));

import { useCallback, useEffect, useRef, useState } from "react";
import { post } from "./api";

/** Run an API call; tracks loading / error state and cancels stale requests. */
export function useApi<T>() {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);
  const ctrl = useRef<AbortController | null>(null);

  const run = useCallback(async (path: string, body: unknown): Promise<T | null> => {
    ctrl.current?.abort();
    const c = new AbortController();
    ctrl.current = c;
    setLoading(true);
    setError(null);
    try {
      const out = await post<T>(path, body, c.signal);
      if (!c.signal.aborted) setData(out);
      return out;
    } catch (e: any) {
      if (e?.name !== "AbortError") setError(String(e?.message ?? e));
      return null;
    } finally {
      if (ctrl.current === c) setLoading(false);
    }
  }, []);

  return { data, error, loading, run, setData };
}

/** Value that only updates after `delay` ms without change. */
export function useDebounced<T>(value: T, delay: number): T {
  const [v, setV] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setV(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return v;
}

  const out: any = { ...a };

## The model

State (x, y, vx, vy), relative air velocity u = v − w (w = horizontal wind, positive = tailwind), and k = ½ρS:

    a = −g ŷ − (k Cd / m) |u| u + (k Cl / m) |u| perp(u)

Inputs: initial speed `v0`, launch angle `theta`, drag `cd`, lift `cl`, mass `mass` (it scales drag and lift as
Cd/m and Cl/m), wind `wind`. Ball diameter 0.22 m, ρ = 1.225 kg/m³. QoIs: range, max height, flight time,
impact speed. Integration is vectorised over samples: 10 000 Monte Carlo trajectories take about 0.2 s.

Every input has a nominal value and can be switched to **uncertain** (normal, uniform or lognormal law with a
given mean and std). Sampling always goes through the unit hypercube and the inverse CDFs, so Monte Carlo,
DoE and Sobol share one code path.

## The six tabs (lessons)

| # | Tab | What it teaches |
|---|-----|-----------------|
| 1 | Simulator | The deterministic model; comparison with the vacuum parabola; range vs angle (the best angle is < 45° with drag); Euler first-order convergence vs dt. |
| 2 | Uncertainty propagation | Monte Carlo (random / LHS / Sobol): spaghetti plot, histogram + KDE, quantiles, P(miss target), 1/√n convergence, FOSM (linearised) comparison, output vs each input. |
| 3 | Design of experiments | Random, LHS, optimized LHS, Sobol, Halton, full factorial; pairwise projections; min distance and discrepancy compared across methods; editable input box. |
| 4 | Surrogate model | Polynomial (1–3), Gaussian process, random forest, MLP; test Q²/RMSE, parity plot, 1D slice with the GP ±2σ band, 2D response surface (prediction / truth / error / GP std), learning curves. |
| 5 | Sensitivity analysis | One-at-a-time tornado, Morris (μ*, σ), Sobol S₁/S_T with bootstrap CIs, on the simulator or on the surrogate, with a cost table ("what if one run took 1 min?"). |
| 6 | Robust design | Choose the means of 1–2 design variables; wind, Cd… act as nuisance parameters. Compares deterministic, mean–variance and chance-constraint optima on a landscape, re-checks each on the true simulator, and runs a tolerance-allocation study (P(hit) vs the std of the design variables). |

With the defaults (target range 55 ± 3 m, wind σ = 2 m/s), the deterministic design (θ ≈ 39°) hits the
target only about 42% of the time. The robust designs pick flatter, faster shots (θ ≈ 18–20°), which are less
sensitive to the wind, and reach about 47–48%.

How it works:

  1. Synthetic experiment. Pick 1–3 parameters to calibrate (v0, Cd, Cl, mass or wind) and set their hidden "true" values. Then choose the number of shots, the angle range, what is measured (range, max height or both), the measurement noise and optional unmodelled wind gusts. A "New data" button redraws the noise.
  2. Prior. Each parameter's law in the left panel is its prior; ticking a parameter makes it uncertain if needed.
  3. Inference. Two methods:
    • Exact grid posterior: one vectorised simulator call, about 0.1 s for 1 parameter, 0.6 s for 2, 3 s for 3. It reruns automatically when the data change.
    • Ensemble MCMC: a stretch-move sampler, with no step size to tune. It runs on a GP emulator by default (about 3 s, emulator trained on 250 simulator runs) or on the simulator itself (slower).
  4. Views: the data with prior and posterior 90% prediction bands, prior → posterior marginals, the joint posterior with correlation, MCMC traces with the burn-in shaded, and the prediction of a new shot at a chosen angle. A "reveal truth" toggle shows or hides the hidden true values.

What students should see:

  • Learning from data: with 8 shots and 1 m noise, the Cd uncertainty shrinks about 6×, and the predicted range at 45° goes from ±2.7 m to ±0.4 m.
  • Identifiability: only Cd/m enters the equations, so calibrating Cd and mass together gives a correlated ridge, not a point. Widen the mass prior (its default σ is only 0.01 kg) to see it clearly; the lesson text says so.
  • Model error: with 3 m/s gusts the model doesn't know about, the 95% interval contains the truth in only 4 of 10 datasets. Raising the assumed noise to 4 brings it back to 9 of 10. A test checks this behaviour.

I also sped up the solver by about 20%: landed trajectories are no longer frozen at every time step, which was safe because their results are recorded at impact. All earlier tests still pass.

Limits:

  • The shots vary only the launch angle; the other inputs stay at their nominal values from the left panel.
